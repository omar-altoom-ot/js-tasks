#  Bookstore & Reading Club
##  Overview

This project is a simple web application for a **community bookstore and reading club**.
It allows users to register their membership, choose reading preferences, and receive a personalized experience using JavaScript.

---

##  Features

* User registration (name & membership type)
* Personalized welcome message
* Book genre selection (fiction / non-fiction)
* Book reservation simulation
* Console logging for user activity
* Multiple JavaScript exercises (if-else, operators, functions)

---

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript


3. Run `index.html` in your browser
